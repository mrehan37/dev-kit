# Skills

Skills are instructions that teach the chef how to perform a particular kind of work consistently.

**What goes here:** Focused, reusable procedures with clear triggers and boundaries.

**What does not:** One-off project instructions, complete recipes, or secrets.

## Skills in this warehouse

- [`project-intake.md`](project-intake.md) — turn a plain-language request into a
  confirmed understanding of the problem and requirements, before any recipe.
